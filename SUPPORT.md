# Support

Use GitHub Issues in the repository that owns the affected component. Include
the version or commit, platform, expected behavior, observed behavior, and a
minimal reproduction.

For installation, setup, pairing, upgrade, and uninstall questions, start in
the [Homebrew Tap issue tracker](https://github.com/codex-remote/homebrew-tap/issues).

Do not include credentials, pairing links, QR codes, project content, personal
paths, or unreviewed diagnostics. Security issues belong in private
vulnerability reports, not public support threads.
